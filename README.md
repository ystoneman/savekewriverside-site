# Legacy website compatibility

This repository preserves https://savekewriverside.org/ using the shared compatibility generator in [the maintained source](https://github.com/ystoneman/savekewriversideprimaryschool-site). Edit website content and recovery behaviour there. This repository contains no full website or promoted public copy.

A verified canonical main release dispatches this workflow only when generated compatibility bytes change. Existing Pages custom-domain settings are preserved. The deployment guard rejects untested and superseded revisions; exact bytes are checked live before completion. See the canonical CONSOLIDATION.md for operation and retry instructions.
